# Healthcare Management Dashboard with AI Chatbot

This project is a healthcare management dashboard designed to support hospitals
and medical staff in monitoring operations and improving patient support.

The system includes an **AI-powered chatbot** using OpenAI, allowing users to
ask questions and receive useful healthcare guidance through a friendly interface.

##  Features
- User-friendly healthcare dashboard
- AI Chatbot powered by OpenAI API
- Real-time interaction with patients/staff
- Visual display of key hospital metrics (if included)
- Secure and simple interface built using **Streamlit**
